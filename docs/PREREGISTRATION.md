# Registered experiment

The machine-readable design is requests/experiment.json. Its canonical digest is recorded by every stage before reading model results. Setup resolves model revisions and environment compatibility. Training refuses unresolved model revisions or an unfrozen preparation manifest.

The planned comparison uses one scientific retrieval corpus, three matched learning arms and one seed. The selected candidate is chosen only on grouped validation. All test rows remain in the denominator, including unavailable methods. Teacher supervision never becomes evaluation gold.

Default promotion requires every registered quality, parity, completeness and serving gate. A failed learned candidate leaves the verified base default. The project can finish with a negative result.

The first local probe found a working Python 3.12.13 interpreter, unavailable ML dependencies, blocked external DNS and an inactive Docker daemon. Model work uses bounded standard public Actions runners. No paid resource is authorized.
