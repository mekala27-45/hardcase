# Decisions and their basis

Selective final-block fine-tuning limits optimizer state and CPU work while allowing a measured representation change. The observed setup probe is evidence/setup/probe.json. This does not establish quality under the benchmark budget.

Per-query negatives avoid treating a positive for another query as an automatic negative. Mined examples remain weak labels. The actual teacher receipt and automated audit are in evidence/preparation. Teacher preference is a diagnostic, not independent relevance truth.

Exact search is appropriate for the declared fixed SciFact corpus and avoids adding approximate-index error to the learning comparison. Document identity and stable ties remain independently testable. No external vector database is required.

ONNX provides an inference-only serving route without Torch or a teacher in visitor requests. The setup probe established export feasibility. Final parity, complete symmetric re-encoding and actual serving measurements are still required for each selected artifact.

The fixed release gate separates model selection from default promotion. An adverse quality result keeps the base default. PostgreSQL transactions bind aliases, generations and receipts; independent fault observers check the boundaries rather than trusting an update return code.
